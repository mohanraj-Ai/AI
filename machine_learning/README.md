# Machine Learning

A collection of regression, classification, and clustering projects and assignments, covering core ML algorithms implemented and explained in Jupyter notebooks.

## 📁 Repository Structure

```
machine_learning/
├── REGRESSION/
├── CLASSIFICATION/
└── CLUSTERING/
```

---

## 📈 Regression

Models used to predict continuous numerical values.

- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Ridge Regression (L2 Regularization)
- Lasso Regression (L1 Regularization)
- Elastic Net Regression
- Support Vector Regression (SVR)
- Decision Tree Regression
- Random Forest Regression
- Gradient Boosting Regression (XGBoost / LightGBM)

---

## 🧩 Classification

Models used to predict discrete categories/classes.

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes (Gaussian / Categorical)
- Decision Tree Classifier
- Random Forest Classifier
- Support Vector Machine (SVM)
- Gradient Boosting Classifier (XGBoost / LightGBM)
- Artificial Neural Network (ANN) based classification

---

## 🔗 Clustering

Unsupervised models used to group similar data points.

- K-Means Clustering
- Hierarchical Clustering (Agglomerative)
- DBSCAN (Density-Based Clustering)
- Mean Shift Clustering
- Gaussian Mixture Models (GMM)

---

## 🛠️ Tech Stack

- **Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, XGBoost
- **Environment:** Jupyter Notebook

---

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/mohanraj-Ai/AI.git
   ```
2. Navigate to the `machine_learning` folder
3. Open any notebook (`.ipynb`) in Jupyter Notebook / JupyterLab / VS Code
4. Install dependencies
   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn xgboost
   ```
